# 多语种改点与分part稿自动整理工具 v1.8.0 使用说明

本工具基于 Python 标准库与 OpenXML 深度排版引擎封装为轻量级免安装 Windows 桌面软件，无任何第三方运行时依赖。

- **左侧六大导航板块 + 极简全局状态栏**：左侧按业务分组提供 **「零散改点整理」**、**「全篇改点整理」**、**「改点稿查重」**、**「英文字数统计」**、**「分part稿整理/合并」** 五大工作台以及「全局配置」下的 **「系统设置」**；右上角精炼展示当前 `模型 | Key 数量 | 黄标连片词数`，并提供 **「系统设置」** 与 **「语种库」** 快捷入口。
- **全局拖拽与实时刷新**：支持直接从桌面或资源管理器把 `.docx` / `.txt` 文件或文件夹拖入对应输入框、表格队列或左侧板块按钮；每次点击运行均创建全新独立工作目录并实时读取磁盘最新文件，同名文档反复修改运行永不残留旧内容。
- **内置在线检查与自动更新**：左下角提供 **「检查软件更新」** 按钮；发现新版本支持一键校验 SHA-256 下载热替换重启（本机加密 API Key 池、常用语种置顶与各项偏好设置均完整保留）。

---

## 一、启动方式

1. **独立单文件版（推荐日常办公使用）**：直接双击 `零散改点整理工具.exe`（无需安装 Python，自适应 100%~200% 高分屏缩放）。
2. **脚本直连版（本机开发/规则同步）**：双击 `启动工具.bat`（直接调用本机 Python 与最新脚本）。

---

## 二、「系统设置」与常用语种置顶（v1.8.0 新增）

点击左侧导航底部的 **「系统设置」**（或右上角快捷按钮）：

1. **API 密钥池、通道与模型设置**：
   - 支持切换 AI 模型、接口通道与多 Key 调度策略，勾选 Windows DPAPI 本机加密保存。
   - 内嵌多行 **API Key 池列表**（每行 1 个 Key，支持 `# 备注`，与「批量检测全部 Key」弹窗实时同步），可随时点击 **「保存设置」**、**「测试连接」**、**「批量检测全部 Key」**（支持一键剔除失效 Key）或 **「清空输入」**。
   - 若未填 API Key、取消勾选 AI 开关或运行中 Key 全部受限，系统自动无感切换**本地位置估算模式**完成标色。
2. **改点高亮与排版规则参数**：
   - **两处黄色高亮自动连片最大间隔词数**：默认 **`3`**（可调范围 `0~20`，填 `0` 则不自动连片）。当同一段内两处黄色高亮之间未标色的英文单词数 `≤` 该数值时，系统会自动将中间间隔连起来标记为黄色高亮，避免标色过于零碎。
3. **常用语种置顶与标准字体库**：
   - 点击 **「管理常用语种与标准字体库...」**（或右上角 **「语种库」**），可在列表中双击语种行、勾选 **「设为常用语种（下拉框置顶）」** 或点击 **「切换选中语种常用置顶」**。
   - 所有工作台的目标语种下拉框会自动按 **`AUTO 自动识别` → `★ 常用置顶语种` → `⏱ 最近使用语种` → `其余语种`** 排序。

## 三、板块 1：「零散改点整理」一键输出定稿

1. **待整理文档与总库实时同步**：
   - 拖入待整理 `.docx`（支持 2 列中英稿自动扩为横向 A4 三列表格）与对应语种总库目录；可点击待整理文档旁的 **「刷新」** 核验最新修改时间，或点击 **「刷新总库」** 强制重建索引。
2. **核对最新中英底稿（可选，v1.8.0 新增）**：
   - 勾选 **「核对最新中英底稿：」** 并点击 **「选文件...」** / **「选文件夹...」**（或直接拖入最新中英底稿 `.docx` 文件或文件夹）：
   - 程序会先将待处理稿与最新中英底稿逐段比对，**100% 保留原始待处理稿的浅蓝底纹、粉红底纹、蓝/红字体颜色、字体字号与批注**，仅将有差异的文字无损更新为最新底稿内容，在输出目录生成 `{原文件名}{YYYYMMDD}更新.docx`，随后自动以更新后的稿件执行三语提取对比！
3. **高亮颜色开关、提取三语原稿与三列同步**：
   - **对比标记高亮颜色**：默认勾选（第 1 列中文自动接受修订并与第 2 列英文、第 3 列外文同步标黄 UP / 标青 RV；同时逐字符保留原稿第 2 列圣经引文蓝字与红字不串色）；**取消勾选则仅输出第 2 列英文对比修订痕迹，不标记任何高亮底色**。
   - **导出对比前的「提取三语原稿」供核对**：默认勾选，同步输出未带对比修订的三语提取原稿便于对照核查。
   - **无改点行彻底剔除 & 单文档平铺输出**：发译者版自动剔除多行表格中无改点的行；单个待整理文档的所有输出直接平铺保存在输出目录中，不生成多余子文件夹。

## 四、板块 2：「全篇改点整理」

1. **两种全篇对比模式自由切换（v1.8.0 升级）**：
   - **模式 A — 按标题列表提取篇目（默认勾选）**：支持粘贴或导入标题清单（`.docx` / `.txt`），自动兼容如 `3-1-39 032 七雷巨响——预言国度的福音将扩展全宇（审判）`、`3-1-37 030 神的作工像人想象得那么简单吗？` 等带单/双编号前缀与括号尾注的标题检索，并在输出文件名中自动保留 `3-1-39 032_` 编号前缀；同名多篇标题自动弹窗勾选确认。
   - **模式 B — 现成双文件夹直连对比（取消勾选顶部模式复选框）**：无需输入任何标题，直接将「最新中英底稿包」与「外文三语文件包」按自然顺序逐篇配对对比，并直接采用最新中英底稿文件名命名输出！
2. **刷新底稿、无改点汇总报告与智能分包**：
   - 点击「最新中英底稿目录」旁的 **「刷新底稿」** 可随时强制刷新底稿拆篇索引；同样支持勾选/取消 **「对比标记高亮颜色」**。
   - **英文无改点篇目自动汇总**：若某篇英文对比完全无改点，自动跳过生成单篇对比文件，并在任务结束时统一生成 **`全篇对比_英文无改点篇目汇总报告_YYYYMMDD.docx`**。
   - **智能分包归档**：仅对比 `1` 篇时直接平铺在输出目录；对比 `≥2` 篇时自动归入 `给译者版/`、`完整留底版/`、`中英最新底稿包/`、`外文三语原稿包/` 四个清晰子文件夹。

---

## 五、板块 3：「改点稿查重」

- 批量拖入待查重 `.docx` 或文件夹并指定「未入库改点包目录」，按第 1 列中文执行 **整段 → 段首 → 段尾 → 着色片段** 四级离线查重，自动生成横向 A4 **`查重结果明细报告_YYYYMMDD.docx`** 及剔除重复段并重算字数的发译者定稿。

---

## 六、板块 4：「英文字数统计」

- 离线毫秒级统计第 2 列英文 `UP`（黄）/ `RV`（青）单词数（`0` 词项自动省略），支持**保留原文档名**、**全篇改点（取首行第 2 列加粗英文标题）**、**零散改点（`God's words [in 关键词]`）**三种命名规则及同步更新开头 `Blue / Yellow highlighted parts...` 说明行。

---

## 七、板块 5：「分part稿整理/合并」

- 支持**多份 `Part 1..N` 文档按序合并**与**单文档内多段 Part 表格一键合并**（自动修复 `gridSpan` 防错位、横向 A4、关闭修订、清除批注、清理句尾空格与格底空行）。
- 严格按第 2 列英文独立同步蓝字 `#0000FF`、可选红字与加粗，识别圣经与神话括号出处字号，并自动套用《各语系字体》标准规范（如泰语 `Angsana New` `18/16/14pt` 等）。
