# 多语种改点与分part稿自动整理工具 v1.7.0 使用说明

本工具基于 Python 标准库与 OpenXML 深度排版引擎封装为轻量级免安装 Windows 桌面软件，无任何第三方运行时依赖。

- **左侧分组可滚动工作台导航 + 顶部全局共享工具栏**：左侧按业务分组可一键切换 **「零散改点整理」**、**「全篇改点整理」**、**「改点稿查重」**、**「英文字数统计」** 与 **「分part稿整理/合并」** 五个专业板块（支持任意板块上下拖动分隔条自由调节设置区与表格/日志高度）；右上角全局工具栏跨板块共享 **模型选择**、**测试连接**、**API 密钥池** 与 **语种与字体库**。
- **全局拖拽支持**：可直接从桌面或资源管理器把 `.docx` / `.txt` 文件或文件夹拖入右侧对应输入框、表格队列、空白处或左侧对应板块按钮！
- **内置在线检查与自动更新**：左下角提供 **「检查软件更新」** 按钮；启动时后台静默检测新版本，发现更新会在顶部提示并支持一键校验 SHA-256 下载替换并重启（本机保存的加密 API Key 池与自定义语种配置均完整保留）。

---

## 一、启动方式

1. **独立单文件版（推荐日常办公使用）**：直接双击 `零散改点整理工具.exe`（无需安装 Python，可拷贝到任意 Windows 64 位电脑运行，自适应 100%~200% 高分屏缩放）。
2. **脚本直连版（本机开发/规则同步）**：双击 `启动工具.bat`（直接调用本机 Python 与最新脚本）。

---

## 二、API 密钥池、多语种与《各语系字体》管理

1. **支持无限个 API Key 轮换 + 离线无感兜底**：
   - 点击右上角全局工具栏 **「API 密钥池」** 按钮可填入无限个 Gemini (`AIza...`) 或 Vertex (`AQ....`) API Key，并统一配置接口通道、均衡轮换/主备秒切策略、批量检测与一键剔除失效 Key（支持 Windows DPAPI 本机加密保存）。
   - **免 Key / 超额绝不停工**：若未填 API Key、取消勾选 AI 开关，或运行途中 Key 全部超额失效，系统自动切换**本地位置估算模式**完成分级与第 3 列外文标色。
2. **多语种与内置《各语系字体》管理**：
   - 点击右上角 **「语种与字体库」** 或各板块 **「管理语种...」** 可打开语种与标准字体配置窗口（保存在同目录 `languages.json`）。
   - 已完整内置《各语系字体》标准映射（如法/葡/西/意/菲/罗/保/波兰/希/塞/克/荷/苗/斯瓦希里语默认 `Georgia`，俄/印尼/越/匈/蒙/德/斯洛伐克语 `Times New Roman`，乌克兰语 `Arial`，印地/尼泊尔语 `Mangal`，缅语 `Myanmar Text`，阿语 `Simplified Arabic`，泰语 `Angsana New` 且自动匹配标题 `18pt` / 正文 `16pt` / 引文出处 `14pt`，韩语 `Malgun Gothic`，希伯来语 `FrankRuehl` 等），并支持查看、修改或为新语种自定义字体。

## 三、板块 1：「📝 零散改点整理」一键输出定稿

1. **文档与总库实时同步**：
   - 拖入待整理 `.docx`（**支持 2 列中英稿自动扩充为横向 A4 三列表格**）与对应语种总库文件夹。
   - **实时读取不取旧缓存**：即使总库文档刚刚在 Word 中修改保存，运行一键整理时也会实时从磁盘读取最新总库正文；也可随时点击总库旁的 **「🔄 刷新总库」** 强制重建全库索引。
2. **同篇重复段落自动合并 & 五级智能检索**：
   - 若待整理原稿中同一中文段落出现多次且涂了不同位置的改点底色，程序会自动将其改点合并至同一行并清除重复行。
   - 支持无标题、非标准标题、段首、着色片段、段尾五级级联检索；未匹配段落优雅跳过（发译者版/无改点版剔除，完整留底版红字提示）。
3. **命名模式、顶部高亮说明行与未入库联动查重**：
   - **命名模式**：默认采用零散标准命名 **`God's words`**（填写关键词如 `15P` 则生成 `God's words in 15P`），也可切换为自定义/保留原文档名。
   - **0 词自动省略 & 顶部说明行**：文件名中若 `UP=0` 或 `RV=0` 会自动省略为 `0` 的项（如仅 `(UP 96 words)`，无改点版不带 `(UP 0 words, RV 0 words)`）；同时根据实际存在的黄/青高亮，自动在文档最上方生成对应颜色的 `Blue highlighted parts need to be reviewed.` / `Yellow highlighted parts need to be updated.` 说明行。
   - **关联「未入库改点包」查重（可选）**：勾选并选择未入库改点包文件夹后，会自动从「发译者版」中剔除与未入库包重复的段落、重算字数并输出查重明细报告。
4. **批注双端无损保留 & 100% 合规直接保存**：
   - 原稿第 2 列批注与总库第 3 列批注、原对齐方式与粗细版式均完整保留，在 Word 中打开绝不报“无法读取的内容”，可直接 `Ctrl+S` 保存。

## 四、板块 2：「📖 全篇改点整理」

1. **输入待对比篇目标题**：
   - 可在多行文本框直接粘贴篇目标题（一行一个），或点击 **「📄 导入标题文档 (.docx / .txt)...」** / 直接拖入标题清单文档。
2. **指定目录并开始对比**：
   - 选择 **「最新中英底稿目录」**（同时支持单篇 `.docx` 底稿与包含数百篇的合集大文档自动拆篇）、**「外文三语总库目录」** 与 **「输出保存目录」**（同样支持可选关联「未入库改点包」去重）。
   - 点击 **「⚡ 开始全篇提取对比（逐篇输出完整版 + 仅改点版）」**：
     - 若遇到如 `第一篇` 等在多卷/多分部中重名的标题，会自动弹出 **「多篇同名标题选择确认」窗口**，列出各候选篇目的完整卷名/分部路径与行数供您勾选确认；
     - 对整篇文章所有段落执行全量对比（无需底稿预先涂底色），自动提取表格首行第 2 列加粗英文标题作为文件名，**一篇一篇独立导出** `完整版` 与 `仅改点发译者版`！

---

## 五、板块 3：「🔍 改点稿查重」

1. **批量载入待查重文档**：拖入多份改点 `.docx` 或整个待处理改点文件夹。
2. **设定「未入库改点包目录」与输出目录**，点击 **「🔍 开始第一列中文四级查重并导出报告」**：
   - 系统按第 1 列中文依次执行 **整段精确/高相似 → 段首 1~3 句 → 段尾 1~3 句 → 着色句子片段** 四级查重（离线毫秒级完成，无需 API Key）。
   - 自动生成横向 A4 **`查重结果明细报告_YYYYMMDD.docx`**（含待处理位置、未入库包重复来源及三列原文对照快照）。
   - 默认同时导出**剔除重复段落后的发译者定稿**，并自动更新顶部高亮说明行、重算剩余 UP/RV 字数与标准文件名。

---

## 六、板块 4：「🔢 英文字数统计」

- 批量拖入 `.docx` 文档即可离线毫秒级统计第 2 列英文 `UP`（黄）/ `RV`（青）单词数（自动排除标点与 `<w:del>` 删除内容，`0` 词项自动省略）。
- **三种文档名规则自由切换**（实时刷新表格预览）：
  1. **保留原文档名**；
  2. **全篇改点：取首行第 2 列加粗英文标题**；
  3. **零散改点：`God's words [in 关键词]`**（填写关键词实时生成如 `God's words in 15P`）。
- 勾选 **「同步在文档开头插入/更新高亮说明行」** 可在重命名/另存的同时自动补齐或修正文档顶部的 `Blue / Yellow highlighted parts...` 说明行。

---

## 七、板块 5：「📚 分part稿整理/合并」

1. **双场景合并支持**：
   - **多文件合并**：拖入 `Part 1 .. Part N` 多份 `.docx` 或整个文件夹，自动按自然序号排序整理或合并为 1 份总文档；
   - **单文件内多 Part 表格合并**：若单个 `.docx` 内部包含多段 `...Part 1`、`...Part 2` 标题与多个独立表格，系统会自动去除中间多余的分 Part 标题并将各表格无缝合并为同一张对齐的三列表格！
   - 自动修复异常 `gridSpan` 合并列，确保所有行三列竖线 100% 严丝合缝对齐。
2. **蓝字、红字与加粗严格镜像第 2 列英文**：
   - 蓝字（`#0000FF`）与加粗完全解耦同步：第 2 列“蓝且加粗”则第 3 列“蓝且加粗”；第 2 列“仅蓝不加粗”则第 3 列绝不误加粗；两个引文之间的普通叙述文字保持常规黑色不加粗；`Question 10:` / `问题 10：` 等冒号前缀自动同步蓝粗。
   - **同步红色字体开关**：处理神话定稿时可勾选 **「同步标记红色字体到第 3 列」**（若外文该段已有红字则自动保留跳过，无红字则自动对齐第 2 列红字区间）。
3. **版面、出处字号与《各语系字体》自动套用**：
   - 统一设为**横向 A4 页面**、关闭修订、清除批注、自动清理段末多余空格与单元格底部多余空行。
   - 同时识别**圣经括号出处**与**神话摘自括号出处**自动设为小号出处字号。
   - 自动套用对应语种标准字体与字号：第 1 列 `宋体`、第 2 列 `Georgia`、第 3 列按语种自动套用标准字体（其中泰语自动套用 `Angsana New` 标题 `18pt` / 正文 `16pt` / 出处 `14pt`，其余语种标题 `14pt` / 正文 `12pt` / 出处 `10.5pt`）。
