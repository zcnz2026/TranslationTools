# 零散改点自动整理工具 v1.6.0 使用说明

本工具基于 Python 标准库与 OpenXML 深度排版引擎封装为轻量级 Windows 桌面软件，无任何第三方运行时依赖。

- **左侧功能标签栏**：左侧可一键切换 **「📝 零散改点整理」**、**「📊 计算文档字数」** 与 **「📚 弟兄交通整理」** 三个工作台。
- **支持直接拖拽文件与文件夹**：无需频繁点“浏览...”，可直接从桌面或资源管理器把 `.docx` 文件或文件夹拖入右侧对应输入框、预览表格、空白区域或左侧对应功能标签！

## 一、启动方式

目录内提供两种启动方式（任选其一）：
1. **独立单文件版（推荐发给其他电脑使用）**：直接双击 `零散改点整理工具.exe`（无需安装 Python 或任何第三方库，可单独拷贝到任意 Windows 电脑运行）。
2. **脚本直连版（本机开发/规则同步）**：双击 `启动工具.bat`（直接调用本机 Python 与 `.agents\skills\scattered-revision\scripts` 最新脚本，修改规则无需重新打包）。

## 二、API 密钥池与简洁状态提示（支持无限个 Key 轮换 & 离线无感兜底）

1. **支持无限个 API Key 轮换**：
   - 可直接在主界面输入框填入多个 Key（用逗号、分号、竖线或直接粘贴多行文本），或点击 **「🔑 批量管理 Key」** 打开多行密钥池编辑器（每行 1 个 Key，支持 `# 账号备注`，自动去重，数量无上限）。
   - **两种调度策略**：
     - **均衡轮换 + 报错秒切（默认推荐）**：多线程并发请求在健康 Key 之间轮流分摊配额，大幅降低触发超速（HTTP 429）概率。
     - **顺序主备 + 报错秒切**：优先使用第 1 个 Key；一旦额度耗尽、超速（429）、失效报错（401/403）或网络波动，毫秒级无缝切换到下一个可用 Key。
   - 在「🔑 批量管理 Key」窗口中可点击 **「🧪 批量检测全部 Key」** 逐一验证可用性，并支持 **「🧹 一键剔除失效 Key」**。
2. **接口类型与简洁中文报错**：
   - **自动识别（推荐，支持混填）**：同一密钥池可混填 `AQ.` 开头（**Vertex AI API Key**）与 `AIza` 开头（**Gemini Developer API Key**），自动识别对应通道且不会产生误导性的跨通道鉴权报错。
   - 所有接口检测与运行提示均为**单行清晰中文说明**（无原始英文 JSON 或代码堆栈刷屏）。
3. **模型选择与安全存储**：
   - 支持切换 `gemini-3.5-flash-lite` 与 `gemini-3.1-flash-lite`。
   - 勾选 **「本机加密记住」** 后，密钥池通过 Windows 系统级 **DPAPI** 绑定当前登录账户加密保存在 `app_settings.json` 中，磁盘不落明文。

## 三、多语种配置与后台自动建立总库索引

1. **内置 35 种常见语言 & 自由新增语种**：
   - 默认预置法、葡、西、德、意、希腊、俄、乌、韩、日、泰、越、印尼、马来、塔加洛、缅、高棉、老挝、阿拉伯、土耳其、波斯、希伯来、印地、乌尔都、孟加拉、波兰、荷兰、罗马尼亚、捷克、匈牙利、保加利亚、瑞典、蒙古、斯瓦希里、阿姆哈拉等 **35 种语言**。
   - 点击 **「➕ 管理 / 新增语种...」** 即可随时新增任意语种（实时保存至同目录 `languages.json`）。
2. **📚 后台自动建立总库索引（多线程增量加速）**：
   - 每当启动软件（自动读取上次保存的总库路径）、点击「浏览...」选定总库文件夹或直接拖入总库文件夹时，后台会自动启用多线程扫描并建立持久化增量索引（缓存在本机 `%LOCALAPPDATA%\ScatteredRevisionTool`，自动过滤临时文件、初筛稿与已输出定稿）。
   - 首次建库完成后，后续仅增量解析新增或修改过的 `.docx` 文档，二次热加载耗时不到 `0.2 秒`，并在日志栏显示 `📚 总库后台索引已就绪：共 X 篇文档（Y 段），支持无标题极速检索`。

## 四、「📝 零散改点整理」一键输出定稿工作流（v1.6.0 全新升级）

### 1. 极简三步操作
1. **拖入或选择路径**：
   - 在页面拖入 `.docx` 文件会自动填入 **「待整理文档 (.docx)」**；拖入文件夹会自动填入 **「对应语种总库目录」**（也可直接拖到指定的「输出保存目录」输入框中）。
2. **按需确认标色模式开关**：
   - 默认勾选 **「使用 AI 辅助分级与第 3 列精准对齐（若 API Key 失效或取消勾选，自动按本地大概位置标色，绝不停工）」**。
   - **免 Key / 断网照常出稿**：若未填写 API Key、主动取消勾选该项，或运行中全部 API Key 额度耗尽/失效，程序**绝不弹窗阻断或报错中断**，会自动切换为 **「本地位置估算模式」**——依据原英文与第 3 列外文的句子及分句相对比例（自动对齐外文完整单词边界，不截断半个词或音标组合符），完成第 3 列黄色（UP）/ 浅灰（RV）高亮标注，并精准统计第 2 列英文单词数！
3. **点击「⚡ 一键输出定稿」**：
   - 程序在后台自动完成全部提取、修订过滤、分级、外文对齐与词数统计，直接生成最终定稿（中间过程文件存于系统安全临时目录并自动清理，输出目录只保留干净的最终定稿）。

### 2. 五级级联智能检索 & 未匹配行优雅跳过
- 即使待整理原稿**没有文章标题**、**标题写法与总库文件名不一致**、或**同一表格混排多篇神话段落**，系统也会按以下 5 级策略自动回退查找：
  1. 优先按标准标题定位对应总库文档；标题缺失、不规范或该篇未命中时自动切换全库索引检索；
  2. 按第 1 列中文全段及**开头前 1~3 句**检索；
  3. 若开头被改写，自动提取单元格内**带底色、高亮或彩色字体的句子片段**在全库检索；
  4. 若仍未命中，自动提取中文**段落结尾 1~3 句**在全库检索；
  5. 结合第 2 列英文词汇重合度与中文相似度交叉校验，杜绝同名开头误匹配。
- **未匹配行优雅跳过**：若极个别行在总库中确实不存在，系统不会报错停机，而是自动跳过该行并在完成弹窗与日志中汇总提示：
  - **发译者版**与**无改点版**：自动剔除未匹配跳过的行；
  - **完整留底版**：完整保留该行第 1、2 列内容，并在第 3 列用红字标注 `【未在总库匹配到原文，已跳过】` 以便人工核查。

### 3. Word 批注无损保留 & 直接 `Ctrl+S` 保存
- 从语种总库第 3 列提取外文段落时，原文档中的 **Word 批注内容（Comments）完整无损保留**，并自动重排全局唯一批注 ID、闭合跨格范围并清理无效扩展引用。
- 生成的所有定稿在 Microsoft Word 中打开**绝不弹出“发现无法读取的内容”修复提示**，核对微调后可直接按 **`Ctrl+S`** 原地保存，无需另存为新文件！

## 五、三份定稿输出、字数统计与排版保真

- **三版本定稿输出（默认勾选）**：
  1. `GR_原文档名_(UP X words, RV Y words)_YYYYMMDD.docx`：直接发给译者的正式版（仅保留有改点的表格，不含未匹配跳过行）。
  2. `GR_原文档名_完整留底版_(UP X words, RV Y words)_YYYYMMDD.docx`：保留全部表格及跳过行红字提示，供整理组留底核查。
  3. `GR_原文档名_无改点版_(UP 0 words, RV 0 words)_YYYYMMDD.docx`：将已匹配但无实质改点的表格单独归档输出。
- **字数统计与「📊 计算文档字数」独立标签页**：
  - 仅统计表格**第 2 列（英文列）**修订后正文的英文**单词数**（标点符号不计入，已删除 `<w:del>` 内容自动排除；**UP** = 黄色高亮，**RV** = 青色高亮）。
  - 在「📊 计算文档字数」页可批量拖入任意三列 `.docx` 文档，离线毫秒级重算 UP / RV 词数并一键新增或更新标准文件名。
- **原稿字体与字号 100% 保真**：
  - 完整保留原文档第 1、2 列及总库第 3 列的字体、字号、段落行距、首行缩进与从右向左（RTL）属性。

## 六、「📚 弟兄交通整理」板块说明

1. **快捷载入与自动排序**：
   - 直接将包含多个分篇 `.docx` 的文件夹或多份 `.docx` 文档拖入「📚 弟兄交通整理」页面，系统自动按分篇序号排序，并将旧版标题或文件名中的 `Part 1` 统一规范化为 `-01`。
2. **深度无损清洗与关闭修订**：
   - 安全拆解所有 `<w:sdt>` 内容控件（绝不丢失内部文字），接受修订、清除批注与多余底色，并自动关闭修订状态（打开文档底部状态栏显示 **`修订: 关闭`**）；自动清理表头上方 `Notice from the Church...` 等冗余英文说明，仅保留规范总标题。
3. **第 3 列蓝字 `#0000FF` 与引文加粗同步 + 弯引号规范**：
   - 自动将英文/外文直引号统一转为弯引号 `“”` / `‘’`（法语书名号 `« »` 与词中省字符自动保留识别）。
   - 同步第 1/2 列的主标题、日期讲员行、`Question X:`、`Answer:` 及段内神话/圣经引文的蓝字与加粗格式。
   - 若原稿第 3 列已保留蓝粗则本地直接规范化并跳过 AI；取消勾选 AI 开关可 100% 纯本地离线秒出。
4. **字号、行距与三列动态均衡列宽**：
   - 表格首行主标题**保留四号（`14pt`）**；正文统一**小四（`12pt`）**；紧跟在闭合引号后的经文/神话出处括号设为**五号（`10.5pt`）**；表格内统一设置**固定值 20 磅**行距，并按三列实际字长动态均衡列宽。
5. **三种输出方式自由切换**：
   - **仅输出各单篇（默认）** / **仅输出汇总合并总文档** / **各单篇 + 汇总合并总文档同时输出**。
