# 零散改点自动整理工具 v1.4 使用说明

本工具基于现有的 `scattered-revision` Python 核心脚本直接封装为轻量级 Windows 桌面软件，100% 复用既有规则与 Word XML 排版保真逻辑。

## 一、启动方式

目录内提供两种启动方式（任选其一）：
1. **独立单文件版（推荐发给其他电脑使用）**：直接双击 `零散改点整理工具.exe`（无需安装 Python 或任何第三方库，可单独拷贝到任意 Windows 电脑运行）。
2. **脚本直连版（本机开发/规则同步）**：双击 `启动工具.bat`（直接调用本机 Python 与 `.agents\skills\scattered-revision\scripts` 最新脚本，修改规则无需重新打包）。

---

## 二、API 密钥池与模型配置（支持无限个 Key 自动轮换 & 报错秒切）

1. **支持无限个 API Key 轮换**：
   - 可直接在主界面输入框填入多个 Key（用逗号、分号、竖线或直接粘贴多行文本），或点击 **「🔑 批量管理 Key」** 打开多行密钥池编辑器（每行 1 个 Key，支持 `# 账号备注`，自动去重，数量无上限）。
   - **两种调度策略**：
     - **均衡轮换 + 报错秒切（默认推荐）**：每次请求在健康 Key 之间轮流分摊并发与 RPM 限速，大幅避免触发超速（HTTP 429）。
     - **顺序主备 + 报错秒切**：优先使用第 1 个 Key；一旦额度耗尽、超速（429）、失效报错（401/403）或网络波动，立即无缝切换到下一个 Key 继续执行，不会中断当前文档整理。
   - 在「🔑 批量管理 Key」窗口中可点击 **「🧪 批量检测全部 Key」** 逐一检查可用性，并支持 **「🧹 一键剔除失效 Key」**。
2. **接口类型**：
   - **自动识别（推荐，支持混填）**：在同一个密钥池中可同时混填两类 Key：
     - `AQ.` 开头 → 自动走 **Vertex AI API Key** 接口（`aiplatform.googleapis.com`）
     - `AIza` 开头 → 自动走 **Gemini Developer API Key** 接口（`generativelanguage.googleapis.com`）
   - 也可手动下拉固定指定 `Vertex AI API Key` 或 `Gemini API Key`。
3. **模型选择**：支持一键切换：
   - `gemini-3.5-flash-lite`（Gemini 3.5 Flash Lite）
   - `gemini-3.1-flash-lite`（Gemini 3.1 Flash Lite）
4. **安全存储**：勾选 **「本机加密记住」** 后，整个密钥池使用 Windows 系统级 **DPAPI** 绑定当前登录账户加密保存在 `app_settings.json` 中，磁盘不落明文。

## 三、多语种配置与自由新增语种

软件默认内置 **35 种常见语言**（法、葡、西、德、意、希腊、俄、乌、韩、日、泰、越、印尼、马来、塔加洛、缅、高棉、老挝、阿拉伯、土耳其、波斯、希伯来、印地、乌尔都、孟加拉、波兰、荷兰、罗马尼亚、捷克、匈牙利、保加利亚、瑞典、蒙古、斯瓦希里、阿姆哈拉等），并支持**随时自行添加任意新语种**（两种方式任选）：

1. **界面可视化添加（推荐）**：
   - 点击主界面「目标语种」右侧的 **「➕ 管理 / 新增语种...」** 按钮；
   - 填写 **语种代码**（如 `SR`，作为定稿文件名前缀 `SR_xxx.docx`）、**语种名称**（如 `塞尔维亚语`）和 **自动识别关键词**（如 `塞尔维亚语, 塞语, 中英塞`；留空也会自动按名称生成），点击 **「➕ 新增 / 保存语种」** 即可立即生效。
2. **配置文件批量编辑**：
   - 所有语种保存在程序同目录的 `languages.json` 文件中（也可在语种管理窗口内点「📂 打开 languages.json」直接用记事本打开编辑），把 `languages.json` 与 `零散改点整理工具.exe` 一起发给同事即可共享全部自定义语种。

## 四、两种工作流模式

### 模式 A：两步走（带人工 Word 复核，最稳妥）
1. 选择 **待整理原稿 (`.docx`)**、**对应语种总库文件夹**、**输出文件夹**。
2. 点击 **「① 第一步：生成初筛稿」**：
   - 自动匹配总库填充第 3 列、过滤浅蓝底色生成第 2 列修订、过滤非改点人称（如 `you -> you(pl)` / `You(s) -> You` 直接接受修订，`You(s) -> you(pl)` 保留改点）、调用模型评估黄（UP）/ 青（RV），生成 `初筛_原文件名.docx`。
3. 点击界面上的 **「打开初筛稿」** 在 Word 中人工检查/微调第 2 列黄、青高亮（保存并关闭 Word）。
4. 点击 **「② 第二步：由初筛稿生成定稿」**：
   - 自动读取确认后的第 2 列黄/青区间（保留全部青色与黄色修订痕迹不接受），将高亮精准映射到第 3 列外文（黄→黄、青→浅灰），统计 `up` / `rv` 词数并在顶部插入说明。

### 模式 B：一键直出全部定稿
- 点击 **「⚡ 一键直出全部定稿（第一步 + 第二步连跑）」**，自动依次完成初筛评估与外文映射，直接生成最终定稿。

## 五、三份定稿输出、命名格式与独立字数统计标签页

- **三版本定稿输出（默认勾选）**：
  1. `GR_原文档名_(UP X words, RV Y words)_YYYYMMDD.docx`：直接发给译者的正式版（仅保留有改点的表格）。
  2. `GR_原文档名_完整留底版_(UP X words, RV Y words)_YYYYMMDD.docx`：保留全部表格（含无改点表格），供整理组留底。
  3. `GR_原文档名_无改点版_(UP 0 words, RV 0 words)_YYYYMMDD.docx`：将完全没有改点的表格单独输出为一份文档。
- **字数统计规则**：
  - 仅统计表格**第 2 列（英文列）**修订后正文的英文**单词数**（标点符号不计入字数，算单词数而非字母数；删除线 `<w:del>` 内容自动排除）。
  - **UP** = 黄色高亮（Yellow）；**RV** = 青色高亮（Cyan）。
- **「📊 计算文档字数 & 更新文件名」独立标签页**：
  - 支持单选、多选或按文件夹批量导入任意三列 `.docx` 文档，离线毫秒级计算第 2 列 UP / RV 单词数，并按 `语言代号_原文档名字_(UP X words, RV Y words)_YYYYMMDD.docx` 自动写入文件名（原文件名已有字数统计则自动更新，没有则自动新增）。
- **原稿字体与字号 100% 保真**：
  - 原文档第 1、2 列的字体（如 `Georgia` / `微软雅黑`）、字号（如 `12pt`）、行距与首行缩进完全保留；从外文总库提取填入第 3 列的段落也会自动对齐原表单元格的字体、字号与段落行距，不会变成默认的 Calibri 小字号。
